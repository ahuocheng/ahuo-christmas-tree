# 超级圣诞树挑战 🎄

一款适合手机游玩的圣诞主题答题游戏。

**[开始游戏](https://ahuocheng.github.io/ahuo-christmas-tree/)**

## 玩法

完成题目，留下你的手势，看看排行榜上的其他玩家。完成答题并保存手势的玩家之间还可以发起挑战。

## 项目结构

- `index.html`：游戏页面与交互
- `supabase.js`：Supabase 客户端脚本
- `SUPABASE-LICENSE`：Supabase 相关许可

项目使用 GitHub Pages 提供页面，排行榜等联网功能依赖 Supabase 服务和网络连接。
